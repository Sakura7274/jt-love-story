# Our Journey Website

This is a simple, extendable one-page site for sharing your relationship story through photos and memories.

## How to use it

- Open [index.html](index.html) in a browser to view the site.
- Edit the `memories` array in [script.js](script.js) to add new entries, photos, and story details.
- Replace the sample image URLs with your own photos whenever you're ready.

## Quick publish command

From the project folder, run:

```bash
chmod +x push-site.sh && ./push-site.sh "Your commit message"
```

This will initialize Git if needed, connect the folder to the GitHub repository, stage your changes, commit them, and push them so GitHub Pages updates the live site.

## Long-term idea
